<details>
<summary>💡 Tipp 1: Die Beschreibung entscheidet, ob der Skill gewählt wird</summary>

Seid konkret, _wann_ der Skill gelten soll, und beginnt mit den Wörtern, die eure Prompts wirklich
enthalten („Buch-Screen“, „neues Feld“, „Formular“, „Server Action“).

</details>

<details>
<summary>💡 Tipp 2: In einem sauberen Kontext testen</summary>

In der Session, in der ihr den Skill geschrieben habt, kennt der Agent das Muster schon. Erst eine
frische Session beweist, dass der Skill – und nicht eure Unterhaltung – die Arbeit gemacht hat.

</details>

<details>
<summary>💡 Tipp 3: Wer entscheidet, ihr oder der Agent?</summary>

Soll der Agent entscheiden, _wann_ er handelt, ist es ein Skill. Wollt ihr es bewusst auslösen
(und ein Argument übergeben), ist es ein Command – `disable-model-invocation: true`.

</details>

<details>
<summary>💡 Tipp 4: Keine Sonderbehandlung für den Edit-Screen</summary>

Der Punkt ist, dass sich die Form wiederholt. Braucht der Command viele zusätzliche Anweisungen
für den zweiten Screen, verbessert stattdessen den Skill.

</details>
