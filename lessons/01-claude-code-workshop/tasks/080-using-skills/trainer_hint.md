## Learning goals

- **Feature:** installing and inspecting skills, `/skills`, automatic vs. explicit (`/skill-name`)
  invocation, progressive disclosure.
- **Concepts:** skills carry procedural, fast-moving knowledge on demand; memory carries
  always-relevant facts.
- **Practice ground:** Prisma schema, migration, and seed from the domain rules.
- **Takeaways:** reach for a maintained skill when the library moves faster than the model; still
  verify the result.

## Facilitation notes

- The moment that sells this: point at a Prisma 7.x pitfall the skill avoided, and ask the room
  whether the agent would have known it unaided.
- Expect at least one participant to hit the driver-adapter or custom-generate-path issue anyway;
  point them at the Pitfalls section rather than solving it for them.
- A failed migration self-correcting is a great live demonstration of the Reason → Act → Observe
  loop — call it out explicitly if it happens.
- Authoring your own skill comes later (custom skills task) — keep this one about using them.

## Time estimate

~45 minutes.
