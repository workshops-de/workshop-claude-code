<details>
<summary>💡 Tipp 1: „claude: command not found“</summary>

Startet eure Shell nach der Installation neu (oder öffnet einen neuen Terminal-Tab) – die
Änderung am `PATH` greift oft erst in neuen Shell-Sessions.

</details>

<details>
<summary>💡 Tipp 2: Berechtigungsfehler bei npm install</summary>

Wenn `npm install -g` mit Berechtigungsfehlern abbricht, nehmt lieber das native
`curl`-Installationsskript, statt zu `sudo` zu greifen.

</details>

<details>
<summary>💡 Tipp 3: Anmeldung hängt</summary>

Die Anmeldung öffnet ein Browserfenster – auf einem eingeschränkten Rechner oder einem System ohne
grafische Oberfläche schaut in der Doku nach alternativen Anmeldewegen, bevor ihr davon ausgeht,
dass etwas kaputt ist.

</details>
