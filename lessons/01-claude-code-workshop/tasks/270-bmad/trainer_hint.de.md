## Lernziele

- **Skills:** BMAD installieren und konfigurieren; einen rollenexpliziten agilen Workflow
  durchlaufen; Moderation und Party Mode nutzen.
- **Konzepte:** Agent-Personas; skalenadaptive Planung; Brief → PRD → Architektur → Stories →
  Dev → QA.
- **Takeaways:** Rollen machen Verantwortlichkeiten explizit; Moderation holt besseres Denken
  hervor.

## Hinweise zur Durchführung

- **Zeitrisiko:** derselbe Hinweis wie bei Spec Kit – im ursprünglichen 3-Tage-Format war das etwa
  ein halber Tag. Liegt die Gruppe zurück, priorisiert Brief → PRD → Architektur → eine
  implementierte Story, statt alle Stories fertigzustellen.
- Schließt den Workshop ab, indem ihr die Ziele der Teilnehmenden vom allerersten Vormittag erneut
  aufgreift und die Ansätze ad hoc, Spec Kit und BMAD nebeneinander vergleicht.

## Zeitbedarf

~90 Minuten; bildet mit GitHub Spec Kit den abschließenden Vergleich des Workshops.
