<details>
<summary>💡 Tipp 1: Claude will etwas ändern</summary>

Im Plan Mode endet Claude eventuell mit einem Plan und fragt, ob es loslegen soll. Wählt
**No, keep planning** und stellt eure nächste Frage. Wer einen Plan freigibt, verlässt den Plan
Mode, und das ist heute nicht das Ziel.

</details>

<details>
<summary>💡 Tipp 2: Antworten ohne Belege</summary>

Klingt eine Antwort plausibel, nennt aber keine Datei, fragt „welche Datei und Zeile zeigt das?“.
Ein Überblick, den ihr nicht prüfen könnt, ist nur eine Meinung. Öffnet eine referenzierte Datei
selbst und vergleicht.

</details>

<details>
<summary>💡 Tipp 3: Zitate sind keine Belege</summary>

Egal, woher eine Behauptung stammt: Claude soll zeigen, wo der Code oder die Konfiguration sie
stützt. Prüft jede Behauptung, auf die ihr euch verlassen wollt.

</details>

<details>
<summary>💡 Tipp 4: Die Historie verrät, wen ihr fragen müsst</summary>

`git shortlog -sn`, `git log --stat` und `git log -- <path>` machen aus „Wer hat das
geschrieben?“ eine kurze Liste. Claude soll das Ergebnis nach Bereichen des Codes gruppieren.

</details>
