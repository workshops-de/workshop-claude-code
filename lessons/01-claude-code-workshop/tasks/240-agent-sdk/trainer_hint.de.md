## Lernziele

- **Skills:** das Agent SDK installieren und ausführen; Tools und Berechtigungen eingrenzen;
  strukturierte Ausgabe zurückgeben; `.claude/`-Features programmatisch laden.
- **Konzepte:** Claude Code als Bibliothek einbetten; wiederverwendbare Agenten; SDK vs. CLI vs.
  Client SDK vs. Managed Agents.
- **Takeaways:** CLI und SDK teilen sich eine Engine; das SDK wählt man für eigene Anwendungen und
  Automatisierung im Produktivbetrieb.

## Hinweise zur Durchführung

- Haltet sowohl einen Python- als auch einen TypeScript-Quickstart bereit, da der Raum
  wahrscheinlich gemischt ist.
- Das ist ein guter Moment, um die Landschaft aus SDK, CLI, Client SDK und Managed Agents grob
  einzuordnen, falls Teilnehmende nach Optionen für den Produktivbetrieb fragen.
- Teilnehmende ohne API Key folgen der Live-Demo. Einen Trainer-Key nie mit dem
  Raum teilen.

## Zeitbedarf

~30 Minuten.
