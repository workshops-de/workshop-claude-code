## Lernziele

- **Skills:** Spec Kit installieren und initialisieren; den vollständigen Spec-Driven-Ablauf
  durchlaufen; eine Spec maßgeblich halten.
- **Konzepte:** Spec-Driven Development; constitution/specify/plan/tasks/implement; Spezifikation
  als Quelle der Wahrheit.
- **Takeaways:** Absicht vor Implementierung; dauerhafte Specs; Struktur skaliert.

## Hinweise zur Durchführung

- **Zeitrisiko:** Im ursprünglichen 3-Tage-Format bekamen Spec Kit und BMAD jeweils etwa einen
  halben Tag. Auf diesen einen Vormittag neben drei weiteren Themen zusammengepresst, sind sowohl
  diese Aufgabe als auch BMAD knapp. Liegt der Raum hinter dem Zeitplan, behandelt den Schritt
  „eine Anforderung ändern“ als optional bzw. Zusatz, statt den Kernablauf zu kürzen.
- Probleme bei der `uv`-Installation sind das häufigste Hindernis – prüft sie im Setup, nicht
  mitten in der Aufgabe.

## Zeitbedarf

~90 Minuten; das ist die aufwendigste Aufgabe im Workshop.
